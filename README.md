# ChoreCraft Legal Documents

This repository contains the legal documents for the ChoreCraft mobile application.

## Documents

- [Privacy Policy](privacy-policy.html)
- [Terms of Use](terms-of-use.html)

## GitHub Pages

These documents are hosted on GitHub Pages and are accessible at:
- Privacy Policy: `https://pickett2k.github.io/chorecraft-docs/privacy-policy.html`
- Terms of Use: `https://pickett2k.github.io/chorecraft-docs/terms-of-use.html`

## Setup Instructions

1. Create a new public repository on GitHub named `chorecraft-docs`
2. Upload these files to the root of the repository
3. Enable GitHub Pages:
   - Go to Settings → Pages
   - Source: Deploy from a branch
   - Branch: `main` (or `master`)
   - Folder: `/ (root)`
   - Click Save
4. Wait a few minutes for GitHub Pages to deploy
5. Update the URLs in your app's `src/constants/legalUrls.ts` file

## Updating Documents

To update these documents:
1. Edit the HTML files
2. Commit and push to the repository
3. GitHub Pages will automatically update within a few minutes
